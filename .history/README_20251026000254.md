
# CoachFleaMart

## 概要
    このアプリケーションは、個人同士がインターネット上でフリーマーケットのように商品の売買を行うWebアプリケーションです。

## 環境構築

### リポジトリの設定

    ①アプリを作成したいディレクトリに移動

    ②リポジトリをクローン
        git clone git@github.com:tokisiro/coachflermart.git

    ③リポジトリ名を変更

    ④リポジトリのURLの変更(開発する場合)

        1 ③で変更したリポジトリと同名のリモートリポジトリをgithubで作成する
        2 ③で変更したリポジトリのあるディレクトリに移動
        3 リポジトリのURLの変更
            git remote set-url origin 作成したリポジトリのurl

### Dockerの設定

    docker-compose up -d --build

### laravelの環境構築

    ①phpコンテナにログインする
        docker-compose exec php bash

    ②composer.jsonに記載されたパッケージのリストをインストールする。
        composer install

### .envファイルの作成

    ①phpコンテナ内で.env.exampleファイルをコピーして.envファイルを作成する
        cp .env.example .env

### Laravelアプリケーションのセキュリティを強化するための暗号化キーを生成

    ①PHPコンテナ内で以下コマンドを実行
        php artisan key:generate

### テーブルの作成

    ①PHPコンテナ内で以下のコマンドを実行
        php artisan migrate

### ダミーデータの作成

    ①PHPコンテナ内で以下のコマンドを実行
        php artisan db:seed
