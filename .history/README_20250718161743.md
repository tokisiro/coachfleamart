
# アプリケーション名

    ・coachfleamart

##　環境構築

### Dockerビルド

    1. Githubでリモートリポジトリを作成

    2. ローカルリポジトリを配置するディレクトリでgit clone コマンドを実行

    ・git@github.com:tokisiro/coachfleamart.git

    3. ディレクトリ構成及び各ファイルを作成

    4. コンテナの構築

    ・docker-compose up --build -d

### Laravel環境構築

    1. laravelのインストール・laravelプロジェクトの作成

    ・docker-compose exec php bash

    ・composer create-project "laravel/laravel=8.*" . --prefer-dist

    2. laravelとデータベースの接続

    ・.envファイルを編集

    3. ステージングエリアに反映

    ・git add .

    4. ローカルに変更内容を記録

    ・git commit -m “メッセージ”

    5. リモートリポジトリに反映

    ・git push origin main

    6. ER図の作成

    ・mkdir src/database/erd
    ・touch src/database/erd/.drawio.png

    7. マイグレーションの作成

    ・php artisan make:migration create_user_products_table
    ・php artisan make:migration create_products_table
    ・php artisan make:migration create_nices_table
    ・php artisan make:migration create_product_comments_table
    ・php artisan make:migration create_product_categories_table
    ・php artisan make:migration create_categories_table

    ・php artisan migrate

    8. シーディングの作成

    ・php artisan make:seeder CategoriesTableSeeder
    ・php artisan make:seeder NicesTableSeeder
    ・php artisan make:seeder ProductTableSeeder
    ・php artisan make:seeder Product_CategoriesTableSeeder
    ・php artisan make:seeder Product_CommentsTableSeeder
    ・php artisan make:seeder UsersTableSeeder
    ・php artisan make:seeder User_ProductsTableSeeder

    ・php artisan make:factory UserFactory --model=User

    ・php artisan db:seed

### fortify インストール

    1・php artisan vendor:publish --provider="Laravel\Fortify\FortifyServiceProvider"

    2. fortifyを登録・公開する
    ・composer require laravel/fortify

    3. config/app.phpへの登録

    ・Laravel\Fortify\FortifyServiceProvider::class,


### メール送信環境の作成（Mailhog）

    1. Mailhogのインストール

    ・docker run -d -p 1025:1025 -p 8025:8025 mailhog/mailhog

    2. .envファイルの設定

    ・MAIL_HOST=mailhog　　->　MAIL_HOST=host.docker.internal

    ・MAIL_FROM_ADDRESS=null. ->  MAIL_FROM_ADDRESS=example@localhost

    3. config/mail.phpの修正

    ・'host' => env('MAIL_HOST', 'smtp.mailgun.org'), ->   'host' => env('MAIL_HOST', 'smtp.mailtrap.io'),

    4. docker-compose.ymlの追記

    ・mailhog:
        image: mailhog/mailhog
        container_name: mailhog
        ports:
        - "1025:1025"
        - "8025:8025"

### stripeの導入

    1.laravelプロジェクトにstripeのHTTPクライアントを入れる

    ・composer require stripe/stripe-php

    2.フロントエンド：Stripeの支払いボタンの追加

    <head>や@section('script')にStripe.jsを追加
