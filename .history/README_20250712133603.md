
# アプリケーション名

    ・coachfleamart

##　環境構築

    1. Githubでリモートリポジトリを作成

    2. ローカルリポジトリを配置するディレクトリでgit clone コマンドを実行

    ・git@github.com:tokisiro/coachfleamart.git

    3. ディレクトリ構成及び各ファイルを作成

    4. コンテナの構築

    ・docker-compose up --build -d

    5. laravelのインストール・laravelプロジェクトの作成

    ・composer create-project "laravel/laravel=8.*" . --prefer-dist

    6. laravelとデータベースの接続

    ・.envファイルを編集

    7. ステージングエリアに反映

    ・git add .

    8. ローカルに変更内容を記録

    ・git commit -m “メッセージ”

    9. リモートリポジトリに反映

    ・git push origin main

    10. ER図の作成

    ・mkdir src/database/erd
    ・touch src/database/erd/.drawio.png

    11. マイグレーションの作成

    php artisan make:migration create_user_products_table
    php artisan make:migration create_products_table
    php artisan make:migration create_nices_table
    php artisan make:migration create_product_comments_table
    php artisan make:migration create_product_categories_table
php artisan make:migration create_categories_table
